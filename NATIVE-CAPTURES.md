# Native Capsule OS capture record

Refreshed 2026-09-26 from the current Capsule OS working tree. Forty-two gallery frames were regenerated by the project’s native drawing harnesses, each in an isolated fixture home with a deliberate theme, material, finish, or text-scale selection. Two Media controller/Shelf frames come from their dedicated project renderer, and the remaining three specialized Material World 08 evidence sheets retain their separately recorded native-render provenance. Native frames are output images of actual drawing functions, not web mockups. The review sheet remains explicitly mixed evidence: its left column is native output and its right column is labeled art direction. None is a VM screenshot, a running OS, or a claim that the captured state is present in a published ISO.

## Reproduction

Run `bash website/render-native.sh` and `bash website/render-native.sh more` from a Linux build environment with the repository’s native build dependencies, then `node website/build-inventory.mjs`. The refresh also applies `tools/draw-shot.sh` options for theme, material, finish and text scale before rendering each surface. Its content-keyed build compiles the current window source. A private temporary home provides fixture data. No personal store, real application installation, disk format, or live connection is requested.

The render scripts retain logs under assets/native/*.render.log for engineering review. The preview server does not serve those logs. Do not publish them. Some harness overlap counters include intentional overlays (for example, a context menu over file icons); screenshots are visually reviewed separately.

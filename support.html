How the percentages work

Each row has four equally weighted evidence gates. The percentage is completed gates ÷ 4. It measures documented evidence coverage, not the share of compatible games or apps, speed, or a predicted completion date.

  1. A — Implemented Capsule execution route or runtime configuration.
  2. B — Runtime actually executed/loaded in recorded testing for this row.
  3. C — Representative content/application executed through Capsule in recorded testing.
  4. D — Current 0.6 installed end-to-end workflow accepted on BOTH target machines.

Dates identify the actual evidence. Earlier private runs remain earlier private runs; they are not new 0.6 installed tests. “Coming soon” marks expected/catalogued systems without a promised date. A failed or inconclusive test stays visible. No system has passed gate D yet.

# Capsule OS website

Public showcase for the Capsule OS project.

Website: https://jonalexinc.github.io/capsule-os-website/

This repository contains only the static website, native UI renders, and labeled material review sheets. The gallery refresh dated 26 September 2026 was produced by the current Capsule OS drawing harnesses with isolated fixture data and distinct real theme/material selections per surface; it is not a gallery of web mockups. Material World 07 was installed from source `293b4a3da537a0b3beae3a501acd1c879cfaf065`; Material World 08 from `c9a9888b435a7ffb751643debef80ad7022507e9` was independently checked read-only in a powered-off COS VM. Neither receipt establishes guest visual fidelity. Material World 08 has no refreshed guest visual proof, and the current stylist review does not approve Cerakote as a whole-UI coated-metal finish. Native captures show real drawing code with documented sample state. Approved concept art appears only where it is visibly labeled as art direction, never as a running screenshot. The offline verification does not replace a guest visual or interaction pass, and none of these images is a compatibility certification or a released ISO.

## Publishing

GitHub Pages publishes the main branch at its root. The .nojekyll file preserves the authored HTML, JavaScript, CSS, Markdown references, and images without a site-generator conversion. Updating these files on main updates the website.
